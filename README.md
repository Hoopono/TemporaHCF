# TemporaHCF
# Plugin base para Spigot 1.8.9

## Compilar
mvn clean package

## Instalar
1. Copia el JAR generado a `plugins/`
2. Reinicia el servidor

## Comandos
- /temporada
- /temporada entrar
- /temporada salir
- /temporada list
- /temporada top
- /temporada admin start
- /temporada admin stop
- /temporada admin reset
- /temporada admin airdrop
